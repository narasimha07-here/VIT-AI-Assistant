# VIT AI Assistant

VIT AI Assistant is a chatbot designed specifically for VIT students to assist with common queries and support related to their academic and campus life.

## Features

*   Chatbot tailored for VIT students
*   Provides quick responses to frequently asked questions
*   Helps with academic schedules, campus information, and event updates
*   Built with Python for easy customization and expansion

## Installation

1.  Clone the repository:
    ```
    git clone https://github.com/narasimha07-here/VIT-AI-Assistant.git
    cd VIT-AI-Assistant
    ```

2.  Install dependencies:
    ```
    pip install -r requirements.txt
    ```
